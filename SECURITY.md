# Politique de sécurité

## Signaler une vulnérabilité

Merci de ne pas ouvrir d'issue publique pour une faille de sécurité.

Utilisez le signalement privé de GitHub : onglet **Security** du dépôt concerné,
puis **Report a vulnerability**.

Indiquez la description de la faille et de son impact, les étapes de reproduction,
et la version ou le commit concerné.
